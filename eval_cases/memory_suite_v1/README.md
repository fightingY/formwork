# V2.2 working-memory development suite

This suite starts with one two-stage follow-up case. The source stage captures a
grounded contract excerpt. Each attempt then runs a no-memory follow-up (M0) and
an explicit-source working-memory follow-up (M1) against identical fresh fixtures.

After M01 passes its three paired attempts, M02 and M03 extend the same ownership
and isolation contract to CLI deployment defaults and request validation behavior.
