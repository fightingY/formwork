# Stable V1.3 开发期验收归档

本目录只保存 Stable V1.3 开发期间的失败复现和局部重跑证据，用于追溯问题来源，
不代表最终发布结果，也不得与正式通过率合并计算。

- `precheck-1`、`precheck-2`、`precheck-3`：结构化输出、终态和修改范围问题的逐轮预验收记录。
- `c01-c02-rerun`：针对 C01/C02 局部修复后的三连跑记录。
- `full-matrix-1`：首次基础设施恢复后的完整矩阵，14/15 通过；唯一失败是普通 C02
  选择未安装的 pytest 后尝试联网安装，意外进入审批。该结果用于推动 verifier 命令复用和
  非 HITL 联网 deny 规则，不计入正式通过率。

Stable V1.3 的唯一正式验收入口是 `acceptance/stable-v1.3/`。正式结论必须来自同一干净
Git 提交、同一固定 Docker 镜像和一次完整 C01/C02/C03/C04/C09 三连矩阵，不再拼接本目录结果。
