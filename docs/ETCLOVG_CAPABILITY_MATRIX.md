## 状态升级规则

- `experimental -> stable`：必须有独立版本验收、固定提交、完整 run/suite 和可复跑命令。
- `not implemented -> experimental`：先有确定性测试，再进入独立实验分支。
- Viewer 或 `.minicc` 中的原始 run 被清理前，必须先确认 acceptance 已保留足够的不可变证据入口。
- 本矩阵不得因 README 或简历措辞而反向提升状态；只能由验收结果驱动。
